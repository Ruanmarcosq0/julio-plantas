# Julio Plantas

Landing page responsiva para uma floricultura, criada em HTML, CSS e JavaScript.

## Publicação

O projeto está preparado para publicação automática na Vercel a partir da branch `main`.

- Alterações na `main`: produção
- Outras branches e pull requests: prévia
- Pasta publicada: `dist`

## Personalização

Antes da versão final, substitua os links genéricos do WhatsApp pelo número comercial e adicione endereço, horário de atendimento e Instagram.
